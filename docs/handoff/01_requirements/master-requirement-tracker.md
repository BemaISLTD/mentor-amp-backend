## Authority and use

The **Consolidated Architecture and Delivery Specification** (`CAS`) is the primary scope and technical authority. The **Greenfield E2E Weekly SDLC Master Plan** (`MP`) is its execution companion. The **Week 0 Greenfield Readiness Plan** (`W0R`) and **Independent Team Task Document** (`ITD`) add readiness, ownership, evidence, and execution controls. Existing code is evidence for classification only and cannot remove or redefine a requirement.

Every item follows: `VERIFY → UNDERSTAND → COMPARE → TEST → CLASSIFY → ACT → RE-VERIFY → RECORD`.

## Status vocabulary

| Status | Meaning |
|---|---|
| Not started | Required work or verification has not started. |
| In progress | Work has started but acceptance evidence is incomplete. |
| Blocked | A named dependency prevents completion. |
| Complete | Delivery team evidence exists; independent acceptance is pending. |
| Accepted | Required technical, actuarial, QA, and governance acceptance is recorded. |
| N/A | Approved non-applicability with decision evidence. |

Classification (`REUSE`, `IMPROVE`, `REFACTOR/REBUILD`, `REPLACE`, `BUILD`, `DO NOT COUNT`) is recorded separately in `docs/handoff/10_assessment/` after verification.
