# Synthetic MYGA sample data

All records in this directory are **SYNTHETIC** and exist only for deterministic software and
actuarial reconciliation tests. They do not contain policyholder or insurer data.

- `anchor_policy.csv` is the $100,000 five-year worked example.
- `synthetic_myga_inforce.csv` contains 25 deterministic illustrative contracts.
- `myga_surrender_charge.csv` contains initial and renewal charge schedules.
- `myga_sc_age_cap.csv` contains attained-age charge caps.

The product remains illustrative and is not a claim of statutory compliance. LifeLib and
regulatory materials are external references only; no external source data is reproduced here.
