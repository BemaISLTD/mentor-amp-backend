# MYGA Sample Data — Synthetic Portfolio

These files provide synthetic in-force contracts, surrender charge schedules, and statutory waiver tables for the **Multi-Year Guarantee Annuity (MYGA) / Fixed Deferred Annuity** engine.

> **Data Integrity Notice:** These files contain entirely synthetic data generated with deterministic random seeds. They contain no real policyholder PII and no proprietary insurer tables.

---

## 1. Inventory of Files

| File | Content | Actuarial Provenance |
| :--- | :--- | :--- |
| `synthetic_myga_inforce.csv` | 25 synthetic MYGA policies across 3, 5, 7, and 10-year guarantee terms | Generated by `backend/scripts/generate_myga_samples.py` with seed `20261231`. Policy `MYGA-0001` is fixed as the LifeLib Anchor Case ($100,000 premium, 5-year guarantee at 4.50%, 10% annual free withdrawal). |
| `myga_surrender_charge.csv` | Tiered surrender charge schedules by policy year for 3, 5, 7, and 10-year contracts | Standard statutory declining scales (e.g. 5-year: 7%, 6%, 5%, 4%, 3%, 0%). |
| `myga_sc_age_cap.csv` | Surrender charge waiver provisions | Statutory RMD, attained age 59½, confinement, and terminal illness penalty waivers. |

## 3. Mathematical Rollforward & Nonforfeiture Rules

### A. Monthly Compounding Credited Rate
Given annual effective rate $i$, the monthly compounding rate $r_m$ is:
$$r_m = (1 + i)^{1/12} - 1$$

### B. Account Value ($\text{AV}$) Rollforward
For month $t$:
$$\text{AV}_{\text{BOM}}(t) = \text{AV}_{\text{EOM}}(t-1)$$
$$\text{InterestCredited}(t) = \text{AV}_{\text{BOM}}(t) \times r_m$$
$$\text{AV}_{\text{EOM}}(t) = \text{AV}_{\text{BOM}}(t) + \text{InterestCredited}(t) - \text{Withdrawal}(t)$$

### C. Free Partial Withdrawal Allowance
For policy year $Y = \lfloor (t - 1) / 12 \rfloor + 1$:
$$\text{FreeLimit}(Y) = \text{free\_withdrawal\_pct} \times \text{AV}_{\text{Anniversary}}(Y-1)$$
Withdrawals up to $\text{FreeLimit}(Y)$ incur zero surrender charges. Amounts in excess incur the schedule surrender charge rate:
$$\text{ChargeableWithdrawal} = \max(0, \text{Withdrawal}(t) - \text{RemainingFreeLimit})$$
$$\text{SurrenderCharge} = \text{ChargeableWithdrawal} \times \text{SC\_Rate}(Y)$$

### D. NAIC Model #805 Minimum Guaranteed Surrender Value (MGSV)
$$\text{MGSV}(0) = \text{Premium} \times \text{mgsv\_premium\_load}$$
$$\text{MGSV}_{\text{EOM}}(t) = \text{MGSV}_{\text{BOM}}(t) \times (1 + r_{\text{mgsv}}) - \text{Withdrawal}(t)$$

### E. Cash Surrender Value ($\text{CSV}$)
$$\text{CSV}_{\text{EOM}}(t) = \max\Big(\text{AV}_{\text{EOM}}(t) - \text{SurrenderCharge}_{\text{FullSurrender}}(t), \, \text{MGSV}_{\text{EOM}}(t)\Big)$$
