# MYGA Sample Data — Synthetic Portfolio & Development Reference

These files provide synthetic in-force contracts, illustrative contractual surrender-charge schedules, and illustrative contractual waiver tables for the **Multi-Year Guarantee Annuity (MYGA) / Fixed Deferred Annuity** engine.

> **Governance & Reference Classification Notice:**
> - These files contain **synthetic development data** generated with deterministic random seeds. They contain no real policyholder PII and no proprietary insurer tables.
> - **MVA Status:** Market Value Adjustment (MVA) is **not modeled** in this development reference. MVA is deferred to future market-linked rider iterations.
> - **Statutory Nonforfeiture Notice:** The MGSV rate (2.00%) is an **illustrative contractual assumption**, not an official statutory derivation under NAIC Model #805. MentorAmp's eventual statutory nonforfeiture engine will derive state-specific allowable minimum rates dynamically.
> - **Contractual Tables:** Surrender charge and waiver tables represent **illustrative contractual examples**, not statutory mandates.

## 3. Mathematical Rollforward & Nonforfeiture Rules

### A. Monthly Compounding Credited Rate
Given annual effective rate $i$, the monthly compounding rate $r_m$ is:
$$r_m = (1 + i)^{1/12} - 1$$

### B. Account Value ($\text{AV}$) Rollforward
For month $t$:
$$\text{AV}_{\text{BOM}}(t) = \text{AV}_{\text{EOM}}(t-1)$$
$$\text{credited\_interest}(t) = \text{AV}_{\text{BOM}}(t) \times r_m$$
$$\text{AV}_{\text{EOM}}(t) = \text{AV}_{\text{BOM}}(t) + \text{credited\_interest}(t) - \text{gross\_withdrawal}(t)$$

### C. Free Partial Withdrawal Allowance & Surrender Charges
For policy year $Y = \lfloor (t - 1) / 12 \rfloor + 1$:
$$\text{FreeLimit}(Y) = \text{free\_withdrawal\_pct} \times \text{AV}_{\text{Anniversary}}(Y-1)$$
$$\text{chargeable\_withdrawal}(t) = \max\Big(0, \, \text{gross\_withdrawal}(t) - \text{FreeLimit}(Y)\Big)$$
$$\text{surrender\_charge}(t) = \text{chargeable\_withdrawal}(t) \times \text{SC\_Rate}(Y)$$
$$\text{net\_withdrawal\_benefit}(t) = \text{gross\_withdrawal}(t) - \text{surrender\_charge}(t)$$

### D. Contractual Minimum Guaranteed Surrender Value ($\text{MGSV}$)
$$\text{MGSV}(0) = \text{Premium} \times \text{mgsv\_premium\_load}$$
$$\text{MGSV}_{\text{EOM}}(t) = \text{MGSV}_{\text{BOM}}(t) \times (1 + r_{\text{mgsv}}) - \text{gross\_withdrawal}(t)$$

### E. Cash Surrender Value ($\text{CSV}$)
$$\text{CSV}_{\text{EOM}}(t) = \max\Big(\text{AV}_{\text{EOM}}(t) - \text{surrender\_charge}_{\text{FullSurrender}}(t), \, \text{MGSV}_{\text{EOM}}(t)\Big)$$

### F. Insurer Cash Flow Sign Convention
- **Positive (+):** Inflow to insurer. Month 1 receives gross single premium ($+\$100,000.00$).
- **Negative (-):** Outflow from insurer. Insurer pays $\text{net\_withdrawal\_benefit}$ to policyholder and pays $\text{maintenance\_expense}$.
$$\text{net\_insurer\_cash\_flow}(t) = \text{premium\_inflow}(t) - \text{net\_withdrawal\_benefit}(t) - \text{maintenance\_expense}(t)$$

## 4. How Noah Uses This Package

Noah is building the MYGA projection engine on `feat/m2b-myga-product`. Here is how Noah should utilize this reference package:

1. **Input Data Ingestion:**
   - Ingest `samples/myga/synthetic_myga_inforce.csv` and `samples/myga/myga_surrender_charge.csv` into the Data Manager / projection setup.
2. **Execute Anchor Model Point (`MYGA-0001`):**
   - Run a 60-month projection for policy `MYGA-0001` with a $4,000 partial withdrawal at month 12.
3. **Export Output Ledger:**
   - Export the monthly projection results to JSON or CSV containing the canonical columns.
4. **Run Cross-Check Verification:**
   ```powershell
   python tools/lifelib_crosscheck/myga_crosscheck.py --run-output <path_to_noah_output.json>
   ```
5. **Evaluation Criteria:**
   - The cross-check tool requires complete key-set agreement (`(policy_id, month)` across all 60 months).
   - All 11 required fields must be present and finite numeric values.
   - Values must reconcile within $\le 10^{-6}$ ($\le \$0.000001$).
   - A tool self-test (running without `--run-output`) is NOT an engine reconciliation.
