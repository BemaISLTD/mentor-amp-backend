# Synthetic MYGA sample data

All records in this directory are **SYNTHETIC** and exist only for deterministic software and
actuarial reconciliation tests. They do not contain policyholder or insurer data.

## File Inventory

- `anchor_policy.csv` is the $100,000 five-year worked example contract.
- `synthetic_myga_inforce.csv` contains 25 deterministic illustrative contracts for portfolio projections.
- `myga_surrender_charge.csv` contains initial and renewal charge schedules.
- `myga_sc_age_cap.csv` contains attained-age surrender charge caps.
- `synthetic_myga_inforce_10001.csv` contains the single-contract reference policy for contract `MYGA-10001` ($100k premium, issue age 62, male, 5-year guarantee at 4.50%, 2.00% GMSV rate).
- `expected_reference_myga_10001.csv` contains the 60-month expected monthly ledger for contract `MYGA-10001`, derived directly from the verified `anchor_case` in `backend/tests/fixtures/myga_reference_simplified_v1.json` (canonical Beginning-of-Month [BOM] withdrawal timing, $4,000 partial withdrawal at month 12, $60/yr maintenance expense).
- `synthetic_myga_inforce_100001.csv` is an identical convenience alias of `synthetic_myga_inforce_10001.csv` keyed by `MYGA-100001`.
- `expected_reference_myga_100001.csv` is an identical convenience alias of `expected_reference_myga_10001.csv` keyed by `MYGA-100001`.

## Generation

All sample files in this directory are deterministically generated by:
```bash
backend/.venv/Scripts/python backend/scripts/generate_myga_samples.py
```

The product remains illustrative and is not a claim of statutory compliance. LifeLib and
regulatory materials are external references only; no external source data is reproduced here.
