# SPIA sample data — SYNTHETIC

These files exist so the Milestone 1 engine can run end to end. **They contain no real people and no published actuarial tables.**

| File | Content | Provenance |
|---|---|---|
| `synthetic_spia_inforce.csv` | 25 synthetic SPIA policies: `policy_id, product_type, issue_date, issue_age, gender, premium, monthly_payment` | Generated by `backend/scripts/generate_spia_samples.py` with a fixed seed (20261231). SPIA-0001 is fixed as the worked example in the contract (issued 2022-03-01, age 67, male, 1,650 USD/month). `premium` is for display only. |
| `synthetic_mortality_gompertz.csv` | Annual mortality `qx` by `age` (40–150) and `gender` (F, M) | Gompertz formula q_x = 1 − exp(−B·c^x·(c − 1)/ln c), with c = 1.10, B = 3.0e-5 (M), 2.0e-5 (F), rounded to 6 decimals. **Terminal age 120:** q_x = 1 from 120 (rows continue to 150 so long horizons never look up a missing age). |

To regenerate: `backend/.venv/Scripts/python backend/scripts/generate_spia_samples.py` (the output is identical every time).

Replace these files with authorized data and an approved mortality table when the Product Owner answers Q-DATA-2 and Q-DATA-3 (`docs/build/03_QUESTIONS_AND_DOCUMENT_REQUESTS_FOR_PRODUCT_OWNER.md`).
